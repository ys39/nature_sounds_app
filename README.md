# 🌿 自然音アプリ (Nature Sounds App)

リラックスできる自然の音を楽しめるWebアプリケーションです。

## 機能

- **8種類の自然音**
  - 🌧️ 雨の音
  - 🌊 波の音
  - 🌲 森の音
  - 🐦 鳥のさえずり
  - 🔥 焚き火
  - 💨 風の音
  - ⚡ 雷雨
  - 💧 小川のせせらぎ

- **操作機能**
  - 各音源の個別再生/停止
  - 音量調整
  - すべての音を一括停止

## 使い方

1. ブラウザで `index.html` を開く
2. 聴きたい自然音のカードをクリック
3. 音量スライダーで音量を調整
4. 複数の音を同時に再生可能
5. 「すべて停止」ボタンで全ての音を停止

## 技術仕様

- **HTML5**: アプリの構造
- **CSS3**: レスポンシブデザイン、グラデーション
- **JavaScript**: Web Audio APIを使用した音声生成
- **Web Audio API**: リアルタイムで自然音を合成

## ブラウザ対応

- Chrome (推奨)
- Firefox
- Safari
- Edge

※ Web Audio APIをサポートするモダンブラウザが必要です
